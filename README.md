# Задание 3 — маска Anonymous

[Открыть WebAR-приложение](https://batir8888.github.io/anonymous-mindar-mask/)

## Файлы
- assets/anonymous-mask.glb — экспорт модели для WebAR, без камеры и света.
- assets/anonymous-preview.png — рендер из Blender.
- index.html, app.js — сцена MindAR Face Tracking.

## Запуск
В этой папке выполните `python -m http.server 8080` и откройте http://localhost:8080.
Нажмите «Включить камеру», разрешите доступ. Нужен интернет для загрузки A-Frame, MindAR и нейросети. При открытии HTML двойным щелчком камера и загрузка модели могут не работать.
На телефоне откройте [опубликованное приложение](https://batir8888.github.io/anonymous-mindar-mask/) и разрешите доступ к камере.

## 3D-модель
Маска создана в Blender и сохранена в репозитории в формате GLB. Лицевая оболочка с толщиной и отверстиями для глаз. Нос и щёки сформированы геометрией; брови, усы, улыбка и бородка — отдельные редактируемые объекты. Модель симметрична, без внешних текстур. Передняя сторона направлена по -Y Blender, после экспорта — по +Z glTF.

## Привязка и стабильность
Якорь 168 (переносица). Ширина лица в MindAR соответствует 1 единице. Начальный масштаб 0.53; положение (0, -0.195, -0.12) компенсирует положение переносицы в модели. Параметры доступны в «Настроить посадку».
Для трекинга используются встроенные фильтры MindAR: filterMinCF=0.001, filterBeta=1. Они сглаживают оценку движения; скрытие маски при потере лица выполняет MindAR. Искусственная задержка видимости не используется, чтобы маска не зависала на фоне.

## Проверка с камерой перед сдачей
1. Фронтально: совместить отверстия с глазами настройками посадки.
2. Медленно повернуть голову на ±30°, наклонить её и приблизиться к камере.
3. Выйти из кадра: маска должна скрыться; вернуться: появиться.
4. Проверить остановку камеры и повторный запуск.
5. Повторить в браузере телефона по HTTPS и при другом освещении.

Модель и экспорт проверяются отдельно от реальной камеры. Стабильность на физических устройствах требует выполнения этого списка; сильные повороты, перекрытие лица и слабый свет снижают точность.
